\begin{abstract}
\begin{spacing}{1.5}

\addchaptertocentry{\abstractname} % Add the abstract to the table of contents
Homeopathic clinical consultation requires exhaustive exploratory case-taking (30--45 minutes) to elicit multidimensional symptom profiles, followed by manual repertorization across massive 19th-century taxonomic repertories. This creates severe clinical bottlenecks and cognitive fatigue in high-volume healthcare settings. Furthermore, a substantial semantic divide exists between informal, colloquial patient descriptions and archaic repertorial rubrics, rendering traditional keyword search brittle.

In this project, we present \textbf{Kent-AI}, an AI-powered conversational clinical assistant for homeopathic case-taking and dense semantic repertorization. Grounded in a digitized open-access database of Dr.~James Tyler Kent's \emph{Repertory of the Homoeopathic Materia Medica} comprising 74,513 hierarchical rubrics, 679 remedies, and 507,179 associations, Kent-AI decouples clinical intake into an empathetic, privacy-preserving multi-stage pipeline. The system deploys a 10-state finite state machine (FSM) intake chatbot powered by a local LLaMA~3 8B model to systematically gather Kent's seven clinical dimensions (Location, Sensation, Modality-Aggravation, Modality-Amelioration, Concomitant, Temporal, and Mental/Emotional). Symptoms are parsed using a token-level \texttt{Bio\_ClinicalBERT} named entity recognizer and a LLaMA~3 negation/coreference resolver. Affirmative symptom queries are retrieved via a 384-dimensional persistent ChromaDB HNSW cosine index over all 74,513 rubrics, and remedies are scored via a classical Kentian grade-weighted and inverse remedy frequency (IRF) algorithm.

To address the complete absence of domain-specific clinical training data, we introduce a synthetic case generation pipeline with automated 4-tier character offset drift repair. On a 100-case pilot benchmark across 25 MIND rubrics, our pipeline achieved 100.0\% JSON schema validity, 100.0\% character offset alignment (0 drift), and 86.9\% lexical diversity. The clinician interacts with the system via a clinical Streamlit dashboard featuring an interactive Totality Matrix grid, reducing case-taking review time to 5--10 minutes while preserving complete medical provenance.

\end{spacing}
\end{abstract}
