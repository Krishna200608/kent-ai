\begin{abstract}
\begin{spacing}{1.5}

\addchaptertocentry{\abstractname}

Classical homeopathic prescribing requires the physician to match a patient's complete symptom totality --- comprising mental, emotional, physical sensation, anatomical location, modality, concomitant, and temporal dimensions --- against over 74,000 hierarchical rubrics indexed in Dr. James Tyler Kent's Repertory. This process is cognitively demanding, time-consuming, and subject to practitioner recall bias. Kent-AI is an AI-powered conversational clinical decision support system designed to automate and augment this workflow using state-of-the-art Natural Language Processing, dense semantic retrieval, and large language model reasoning.

The system integrates four fine-tuned biomedical transformer encoders (BioLinkBERT-Base, PubMedBERT, Bio\_ClinicalBERT, and DeBERTa-v3) totalling 414 million parameters, trained on a bespoke synthetic dataset of 19,732 clinical cases annotated with 99,854 entities across 15 BIO token labels spanning 7 Kentian symptom dimensions. A ChromaDB HNSW vector index encodes all 74,513 rubrics using \texttt{all-MiniLM-L6-v2} sentence embeddings, enabling sub-18 millisecond semantic retrieval. A QLoRA-fine-tuned BioMistral 7B large language model serves as a clinical reasoning arbiter in a two-stage hybrid extraction pipeline, achieving 47.59\% Micro F1, 100\% JSON schema validity, and 99.73\% clinical grounding on the held-out test set.

A doctor-in-the-loop Streamlit clinical workstation implements a 4-step consultation stepper (Intake, Review, Analysis, Report), an interactive Totality Matrix, a persistent Case Library, and a multi-page ReportLab PDF exporter. The system is validated by 195 automated tests across 22 test modules. BioLinkBERT achieves the highest Token-Level BIO F1 of 34.86\%, PubMedBERT achieves the highest Dense Rubric Recall@20 of 41.56\%, and DeBERTa-v3 achieves the highest Top-5 Simillimum Remedy Accuracy of 42.16\% under narrative-embedding mode. Kent-AI represents the first systematic application of large-scale biomedical NLP ensembling to classical homeopathic repertorization, with a fully open-source, clinically verifiable implementation.

\textbf{Keywords:} Homeopathic Repertorization, Biomedical Named Entity Recognition, Dense Retrieval, Clinical Decision Support, Large Language Models, Parameter-Efficient Fine-Tuning, QLoRA, ChromaDB.

\end{spacing}
\end{abstract}
